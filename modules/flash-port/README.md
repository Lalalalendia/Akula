# Akula: первый самостоятельный перенос SWF4 → Rust

Исследовательский преобразователь. **Он не использует Flash Player, Ruffle или среду AVM при запуске результата:** команды разбираются один раз, при преобразовании создаются обычные операторы Rust. Проверено только на ограниченном подмножестве SWF4; это **не** готовый импорт игр в окно «Акулы».

## Что работает

- Несжатые FWS версии 4, одна временная шкала с одним кадром.
- Теги `DoAction`, `ShowFrame`, `SetBackgroundColor` (цвет пока не рисуется), `End`.
- Команды AVM1: `Push` (строка UTF-8, float, int, boolean, null, undefined), `Trace`, `Add`.
- Генерация Rust-кода **без цикла интерпретации байткода SWF**, компиляция в самостоятельную программу.
- Отказ при неизвестных тегах, действиях, некорректных длинах и переполнении стека во время генерации; лимит 8 МиБ входного файла.

## Пример

```sh
cargo test --manifest-path modules/flash-port/Cargo.toml
cargo run --manifest-path modules/flash-port/Cargo.toml -- test.swf generated.rs
rustc --edition=2024 generated.rs -o generated
./generated
```

Встроенный тест сам создаёт файл формата SWF4 как в [SWFRecomp trace_swf_4](https://github.com/PeerInfinity/SWFRecomp-CC/tree/master/SWFRecomp/tests/trace_swf_4), генерирует Rust, запускает `rustc` и проверяет строку `sup from SWF 4` **без исходного SWF в исполнительной программе**.

## Границы и дальнейшие задачи

- Это строго **P0-A** (SWF4 Trace и арифметика). Верификация арифметики AS1 на эталонном Flash ещё нужна: для `Add` использована предварительная числовая семантика; часть старых строковых случаев отличается от AS3.
- Нет CWS/ZWS, AVM2/AS3, непустых сцен, прыжков, функций, событий, графики, звука, сохранений. Неизвестные конструкции **не пропускаются**.
- Строки SWF4 исторически могут быть не UTF-8: они отклоняются до появления корректного декодера.
- Это отдельный Rust-пакет в `modules/`, не участник тяжёлой рабочей области `aquilum-app`. Не добавлять его зависимости в основной Cargo workspace до появления реального пути UI.
- Следом: заменить узкий ручной разбор SWF на библиотеку `ruffle/swf` (после оценки ограничений распаковки), сохранить GameCodeIR и реализовать представление сцен. AVM1 и AVM2 должны иметь отдельные проверки семантики.

Работы: GAMES-RUST-01 (часть FWS4), GAMES-RUST-02 (узкая Action IR), GAMES-RUST-03 (узкая AVM1), GAMES-RUST-04 (самостоятельный Rust Trace).

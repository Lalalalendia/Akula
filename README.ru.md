# Akula — Акула

**Akula — нативная локальная среда для работы с собственными файлами, документами и знаниями.** Основной код написан на Rust, настольный интерфейс — Masonry/winit, без WebView.

**Направление проекта:** в первую очередь мы делаем Akula для собственных задач. Отзывы других пользователей полезны как материал для изучения, но не задают список обязательных функций и не определяют наши приоритеты.

**Состояние на 19 октября 2026 года: активная разработка, не публичный релиз настольного приложения или синхронизации.** На [странице релизов Akula](https://github.com/Lalalalendia/Akula/releases) пока нет готовых сборок. Не путайте их с [релизами Aquilum](https://github.com/Freaction/Aquilum/releases).

## Принципы

- **Исходные файлы важнее приложения.** Markdown-заметки и вложения лежат в обычных папках и должны оставаться доступными без Akula, аккаунта или конкретного облачного сервиса.
- **Сначала локальная работа.** Открытие, редактирование, поиск и чтение документов не должны зависеть от работающей синхронизации или системы плагинов.
- **Никакой тихой потери данных.** Конфликты, ошибки записи, прерванные операции и внешние изменения нужно показывать и уметь безопасно восстанавливать, а не молча перезаписывать.
- **Обычный редактор должен оставаться простым.** Дополнительные инструменты не должны мешать работе с отдельным Markdown-файлом.
- **Развиваем то, что нужно нам.** Другие проекты и комментарии пользователей — источники идей и проверок, а не чужая дорожная карта.

## Что уже есть в репозитории

| Направление | Фактическая граница готовности |
| --- | --- |
| Desktop и Markdown | В коде есть нативный редактор, локальные файлы, вкладки, поиск, ссылки, история и навигация. Приёмка установленного продукта — отдельная задача. |
| Книги и материалы | Есть компоненты локальной читалки и заметок к источникам; поддержку форматов и полный UX нужно проверять на настоящих сборках. |
| Сохранность файлов | Есть File Gate, история редакций, механизмы конфликтов и восстановления. Продолжаются проверки нескольких процессов, сбоев и разных ОС. |
| Синхронизация S3/MinIO | Разрабатываются транспорт, манифесты, журнал и защищённые операции. **Полноценная пользовательская синхронизация двух устройств ещё не принята.** |
| Расширения | Есть начальные контракты разрешений и хоста. Готового универсального runtime плагинов пока нет. |
| Canvas и Bases | Есть начальный разбор структурированных файлов и интеграция для чтения, но не полноценное редактирование. |
| Веб, мобильные клиенты, совместная работа, Nextcloud | Исследования и возможные будущие направления, **не готовые функции**. Эксперименты P2P также не являются выпущенным продуктом синхронизации. |

Это технический статус компонентов, а не обещание их промышленной готовности. Актуальную ситуацию нужно проверять по [PR](https://github.com/Lalalalendia/Akula/pulls), CI и коду, а не только по факту слияния изменений.

## Сборка из исходников

Потребуется актуальный стабильный Rust и зависимости для выбранной ОС. Подробности есть в [DEVELOPMENT.md](DEVELOPMENT.md) и [aquilum-app/README.md](aquilum-app/README.md), но часть этих инструкций унаследована от Aquilum и пока описывает его упаковку; **разделы о релизах и скачивании не являются инструкцией по установке Akula**.

```sh
cd aquilum-app
cargo build -p aquilum-native
cargo test --workspace
cargo run -p aquilum-native
```

На Windows сохранился сценарий сборки и запуска `aquilum-app/native/run.bat`. Для разработки используйте отдельную тестовую папку и резервные копии важных материалов.

## Релизы, установка и обновления

У Akula **ещё нет собственного опубликованного установщика, подписанного канала обновлений и публичного релиза**. Работа над упаковкой и установкой в репозитории ведётся, но готового дистрибутива это не означает. Не следует устанавливать Aquilum по ссылкам из старого README, думая, что это Akula.

Некоторые внутренние имена пока унаследованы от исходного проекта: `aquilum-core`, `aquilum-native`, `Aquilum.app`, идентификаторы приложения и пакетов. Это переходные технические названия, **а не подтверждение готового установщика Akula или безопасной миграции**. Не устанавливайте экспериментальную сборку поверх существующего Aquilum.

До объявления релиза необходимо проверить установленное приложение: сохранность и восстановление файлов, обновление и откат, реальные пользовательские сценарии на поддерживаемых ОС. Для синхронизации двух клиентов предусмотрена отдельная приёмка.

## Структура исходников

- `aquilum-app/core/` — файлы, история, поиск, компоненты Sync и общая логика.
- `aquilum-app/native/` — нативный интерфейс и рендерер.
- `docs/` — технические решения и результаты проверок.
- `scripts/` — скрипты разработки, упаковки и установки; перед запуском проверяйте их предположения.

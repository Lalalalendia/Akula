## Результат

Перенесена и адаптирована логика из #686. До смены папки приложение синхронно ожидает завершения уже поставленного в очередь сохранения и проверяет результат. При ошибке записи или конфликте оно оставляет активные базу, вкладку, редактор и локальный текст на месте, показывает предупреждение и снова открывает список папок. Новая папка добавляется в список известных только после успешного сохранения. Выбор уже открытой папки закрывает список без лишней записи и без потери черновика. Закрытие активной базы использует ту же проверку сохранения.

Добавлены четыре сквозных сценария в App Harness:

1. Ожидающая правка записывается до смены папки.
2. Ошибка записи при замене файла каталогом сохраняет активный редактор и исходные байты; новая папка не запоминается. После восстановления файла ручной повтор успешно сохраняет черновик и переключает папку.
3. При конфликте исходный файл сохраняет внешнюю версию, локальная версия остаётся в редакторе и в защитной Markdown-копии.
4. Выбор текущей папки не сбрасывает и не записывает несохранённый черновик.
